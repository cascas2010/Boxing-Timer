# v1.3.6 UI 素材拆分方案

## 设计基准

- 基准画布：540 × 1120（9:18.67），运行时保持纵横比居中缩放，超长屏上下延展深蓝观众席，较短屏整体等比缩小。
- 素材全部放在 `app/src/main/res/drawable-nodpi/`，使用 PNG 无密度资源，绘制时关闭位图滤波，保持像素硬边。
- 页面采用“素材层 + 透明交互层”：素材负责体育馆、标题、拳套、面板、按钮、拳手和擂台；`EditText` 与点击热区覆盖在素材对应位置。
- 不把整张参考图作为页面背景。参考图只用于裁切独立美术部件及生成竞技场局部素材。

## 动态文字与缩放

- 首页四个数值由透明 `EditText` 显示，使用黄色粗体等宽字，并带黑色硬阴影；第四行标签由代码绘制为“倒计时提醒”。
- 回合牌、状态文字和按钮文字由代码绘制，避免把示例数值固化在素材里。
- 倒计时保留七段数码管代码绘制，使用黄色高亮、暗段、黑色硬阴影和扫描线。
- 所有素材先按 540×1120 的设计坐标布局，再取 `min(viewWidth/540, viewHeight/1120)` 等比缩放；内容水平居中，避免拉伸人物和字体。
- 小于 360dp 宽度时仍保持同一设计坐标，仅整体缩小；超长屏剩余区域由深蓝底色填充。
