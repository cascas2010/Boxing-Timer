# v1.3.8 UI 视觉差异报告

## 对比依据

- 用户于 2026-10-13 提供的两张“左侧原型、右侧 v1.3.7 实机”训练页对比图。
- 本轮只处理训练页状态栏、底部按钮控制台及必要版本号，不改变计时、回合、铃声、后台服务、状态机和点击行为。

## 已修正差异

### 状态提示栏

- 清除了计时面板素材内原有固定状态文字和矩形覆盖层。
- 新增独立 `ui_timer_status_panel.png`，使用上宽下窄的倒梯形轮廓，并与计时器下边框直接衔接。
- 状态栏包含深蓝扫描线、青蓝顶部与侧边高光、钢蓝主体和深色下阴影，不再出现矩形补丁接缝或旧文字残片。
- “训练中 / 休息中 / 已暂停”继续使用同一状态栏和硬边描边位图；文字两侧加入对称长青色横线，整体垂直居中。

### 底部按钮区

- 新增全宽 `ui_timer_controls_dock.png`，在一个素材内连续呈现拳台地面、蓝色暂停按钮、红色结束按钮及其外框和阴影。
- 移除运行时对两个独立按钮底图的拼接，消除了按钮外围方块接缝、错色底板和突兀棋盘。
- 按钮文字仍为独立硬边描边位图，以支持“暂停 / 继续”的动态切换；透明点击热区位置和尺寸未改变。

## 视觉结论

合成预览中，状态栏已经与计时器形成一个连续组件，三种动态状态不会暴露旧字；按钮和拳台地面来自同一张全宽素材，外部边缘连续。当前环境没有连接 Android 真机或模拟器，不同屏幕状态栏安全区仍需安装后做最终截图确认。
