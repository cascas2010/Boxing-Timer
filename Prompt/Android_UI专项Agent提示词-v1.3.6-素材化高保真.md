# Android UI 专项 Agent 提示词 v1.3.6：素材化高保真 UI 重构

你现在执行的是“像素美术素材化高保真 UI 重构任务”，不是 Canvas 草图临摹任务，也不是自由设计任务。

## 一、任务背景

项目目录：

`D:\WangDao\CodexProject\boxing-timer`

参考图目录：

`D:\WangDao\CodexProject\boxing-timer\source`

用户已经实测 v1.3.5，认为 UI 仍然明显简陋。原因是当前实现主要靠 Android Canvas 手绘，视觉密度、像素美术质感、层次、阴影、人物和背景细节都达不到参考图效果。

v1.3.6 的目标不是继续小修 Canvas，而是改为“美术资源化 UI”：

- 背景、标题、拳套、皇冠、拳手、擂台、观众席、按钮、面板等，尽量用独立 PNG/WebP 像素素材承载。
- Android 控件只负责真实交互，覆盖在视觉素材对应位置。
- 保留 v1.3.5 的计时功能基线，不修改计时规则。

## 二、最高优先级规则

1. 禁止继续用简单 Canvas 矩形、线条、圆形冒充完整像素美术。
2. 禁止用默认 Android 按钮、输入框、Material 卡片外观。
3. 禁止把整张参考图直接作为不可交互背景。
4. 禁止业务逻辑 agent 擅自调整 UI 视觉。
5. UI agent 不得修改计时规则、铃声规则、回合规则、后台计时规则。
6. 如果缺素材，必须先产出素材清单和素材制作方案，不能静默用色块代替。
7. 如果无法达到参考图级别，必须明确列出差异，不得宣称完成。

## 三、v1.3.6 目标

以参考图为准，重构两个页面：

### 设置首页

App 启动后直接进入设置首页，首屏必须看到完整可操作界面。

必须包含：

- 像素风体育馆背景；
- 顶部灯光、观众席、左右拳手海报；
- 皇冠；
- 大标题“拳击计时器”；
- 红色拳套；
- 四行参数设置：
  - 训练时间；
  - 休息时间；
  - 回合数；
  - 倒计时提醒；
- 每行右侧上下箭头按钮；
- 黄色像素风“开始训练”按钮；
- 底部擂台、围绳、角柱、地面和两个小拳手。

### 训练计时页

点击“开始训练”后进入训练计时页。

必须包含：

- 体育馆背景；
- 左右拳手海报；
- 中央星光和灯光；
- 回合牌；
- 左右月桂；
- 大型黄色数码管倒计时；
- 状态文字“训练中 / 休息中 / 已暂停”；
- 背向拳击手，双手举起；
- 擂台、围绳、角柱；
- 蓝色“暂停 / 继续”按钮；
- 红色“结束训练”按钮。

## 四、实现路线

v1.3.6 必须采用“素材层 + 透明交互层”的结构。

### 1. 素材层

优先建立独立素材资源，放入：

`app/src/main/res/drawable-nodpi/`

建议资源命名：

- `ui_home_background.webp`
- `ui_timer_background.webp`
- `ui_home_title.webp`
- `ui_timer_round_panel.webp`
- `ui_home_settings_panel.webp`
- `ui_home_row_panel.webp`
- `ui_home_start_button.webp`
- `ui_timer_panel.webp`
- `ui_pause_button.webp`
- `ui_end_button.webp`
- `ui_gloves.webp`
- `ui_crown.webp`
- `ui_boxer_back.webp`
- `ui_ring_footer.webp`
- `ui_digit_0.webp` 到 `ui_digit_9.webp`
- `ui_digit_colon.webp`

如果无法一次性做全部素材，至少必须优先素材化：

1. 首页背景；
2. 训练页背景；
3. 首页标题；
4. 设置面板；
5. 开始按钮；
6. 训练页计时面板；
7. 背向拳击手；
8. 暂停和结束按钮。

### 2. 交互层

真实可交互控件必须覆盖在素材对应位置：

- 输入框使用透明背景；
- 文本颜色、字号、位置必须与素材对齐；
- 上下箭头按钮可以使用透明热区或素材按钮；
- 开始、暂停、结束必须是真实点击区域；
- 不允许用户点击到“假按钮”没有反应。

### 3. 数码管

倒计时数字优先使用数字素材。如果素材不齐，可以保留代码绘制七段数码管，但必须达到参考图质感：

- 黄色发光；
- 硬边像素；
- 深色背景；
- 比例接近参考图；
- 不允许使用普通 TextView 数字冒充。

## 五、代码组织

UI 相关代码集中在：

`app/src/main/java/com/wangdao/boxingtimer/ui/`

建议结构：

- `ArcadeHomeView`：首页交互层和素材布局；
- `ArcadeTimerView`：训练页交互层和素材布局；
- `ArcadeAssetLayout`：按屏幕尺寸计算素材和热区坐标；
- `PixelDigitView` 或 `PixelDigitRenderer`：数码管显示；
- `ArcadeTheme`：颜色、字号、比例常量。

`MainActivity` 只允许做：

- 创建首页 / 训练页；
- 读取输入；
- 监听按钮；
- 调用计时服务；
- 渲染计时状态。

不得把视觉绘制重新塞回 `MainActivity`。

实现时必须做到：

- 不再以 `ArcadeScenePainter` 作为整页主视觉方案；
- 可以保留少量 Canvas 用于辅助效果，例如光效、数码管、边框微调；
- 页面主视觉必须来自素材；

- 首页第一屏不得只看到背景或标题；
