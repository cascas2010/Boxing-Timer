# v1.3.7 UI 视觉差异报告

## 对比基准

- 原型：用户提供的 90 年代街机像素风双页原型图。
- 实机问题样本：2026-10-12 提供的 6 张“左侧原型、右侧 v1.3.6 实机”对比截图。
- 本次范围：仅 UI 绘制、视觉素材、输入控件布局及版本号，不修改计时、回合、铃声、后台服务或状态机。

## 已修正差异

1. 首页设置区改为一个完整金属外框，四行等高、等距，每行保留独立粗金属上下边框；“回合数/倒计时提醒”之间的分隔线已恢复。
2. 透明输入控件只覆盖数值槽，不再以黑色矩形遮挡金属边框或分隔线。
3. 首页头部直接采用原型素材化裁切：简洁像素皇冠、大黄字红阴影标题、完整红拳套均完整露出，去除了 v1.3.6 的复杂皇冠射线与遮挡。
4. 训练页黄色七段数字缩小并垂直居中，完整位于青蓝金属计时器内框。
5. “训练中/休息中/已暂停”“暂停/继续”“结束训练”改为统一硬边描边位图文字，字号、阴影和居中方式统一。
6. 训练页底部突兀棋盘替换为深蓝擂台地面层，状态文字不再被背景遮挡。
7. 产品文案继续使用“倒计时提醒”。
