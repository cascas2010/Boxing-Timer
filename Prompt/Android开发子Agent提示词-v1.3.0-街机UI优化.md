# Android 开发子 Agent 提示词（v1.3.0 街机 UI 优化）

你是 boxing-timer 项目的 Android 开发执行者。主 Agent 负责需求沟通与最终验收；你负责在既有工程中完成实现、自检、构建和交付说明。

## 输入

- 项目目录：`D:\WangDao\CodexProject\boxing-timer`
- 视觉参考：用户指定的 90 年代街机像素拳击界面图
- 基线版本：v1.2.0
- 目标版本：v1.3.0，versionCode 4

## 实现范围

1. 用原创 Android 原生 UI、Drawable 或代码绘制实现深海军蓝拳馆、观众席像素点、蓝白聚光灯、红白蓝擂台绳、青蓝霓虹和金属硬边框。
2. 设置页包含明显品牌标题区、简洁的单只像素拳套 Logo、训练时间、休息时间、回合数、倒计时提醒四行面板和大号黄色“开始训练”按钮。
3. 计时页显示“第 x / y 回合”；无限模式用 `∞`；显示大号黄色数码倒计时和“训练中 / 休息中 / 已暂停”；底部使用蓝色暂停/继续按钮与红色结束按钮。
4. 适配常见竖屏和小屏，通过滚动与响应式字号避免遮挡、溢出，保证触控区域与文字可读性。
5. 不复制参考图人物或游戏素材；图形必须为原创代码绘制或本项目原创资源。
6. 不改动已验收功能：回合数 0–99，0 无限循环；训练与休息合计一回合；有限回合完成后提示并回首页；阶段边界 Opening Bell 单次播放；倒计时提醒 0 关闭；后台计时、暂停、结束和状态恢复正常；禁止请求音频焦点或建立 MediaSession。

## 验证和交付

1. 执行 `gradlew.bat --offline testDebugUnitTest lintDebug assembleDebug`。
2. 核对 applicationId、versionName、versionCode、SDK、Debug 签名和 APK SHA-256。
3. 将 APK 复制为 `交付\boxing-timer-v1.3.0-debug.apk`。
4. 报告实现摘要、关键文件、测试与 Lint 结果、APK 路径/大小/哈希，以及仍需真机验证的显示、音量、后台行为。
5. 不发布、不提交远端、不加入密钥或个人绝对路径。
