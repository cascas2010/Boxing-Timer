## 本轮 UI 拆分

- `ArcadeHomeView`：首页可操作 UI，包含四项输入和开始按钮。
- `ArcadeTimerView`：倒计时页可操作 UI，包含回合、倒计时、状态、暂停/继续、结束。
- `ArcadeHomeHeroView`：首页赛事标题区，包含灯光、拳击海报、大标题和拳套视觉。
- `PixelRingFooterView`：首页底部拳台和红蓝拳手视觉。
- `PixelBoxerView`：倒计时页拳手和拳台视觉。
- `ArenaBackdropView`：公共赛场背景层，不参与点击和输入。
- `MainActivity`：只负责业务协调、输入读取、服务启动/结束、状态转发和完成弹窗。

## 用户诉求对应

- 进入主界面后直接是可操作的参考图风格 UI，不再是启动页或海报页。
- UI 已单独拉出到 `ui` 包；后续只改视觉时应优先交给 UI 专项 agent。
- 功能 agent 不应重新设计 UI，只做业务接线。
- 测试 agent 单独验收 UI 层级、可操作控件和构建产物。
